# CHA MAHIKHA — Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Personal assets

- Add your own portrait at `assets/profile.jpg`. Until then, the homepage displays a neutral monogram placeholder; no stock or generated person is used.
- Replace `assets/resume.pdf` with your current resume when you need to update it.
- Add certificate images and files to `assets/certificates/`, then update the corresponding gallery cards in `index.html` with the image and certificate URL. Supplied certificate images are included in this folder.
- Project cards link to the supplied `TM-audio` and `predict-maintain` branches in the `Mahikha` repository.

## Preview

Open `index.html` in a browser. The Google Fonts stylesheet is optional; system serif and sans-serif fonts are used as fallbacks.
